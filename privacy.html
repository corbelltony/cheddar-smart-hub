What Calendar access is for, where information is kept, and how you stay in control.

The purpose is simple: show your appointments on your personal dashboard. This public information website does not access your Calendar or receive your event data.

1. About Cheddar

Cheddar Smart Hub is a personal smart-home dashboard running on a Raspberry Pi managed by its owner. It brings together a local calendar view, weather information, and navigation to media services.

This policy describes the Google Calendar integration in Cheddar and this public information website. Separate services you choose to open, including Google and media providers, have their own privacy policies.

2. Google Calendar access

Calendar access is optional and requires your authorization through Google. Cheddar requests the read-only Google Calendar permission, https://www.googleapis.com/auth/calendar.readonly.

The current integration retrieves events from your connected account's primary calendar for the date range displayed on the dashboard. The event information kept for display includes event identifiers, titles, start and end dates or times, and whether an event is all day.

This information is used to display appointments and navigate the local Calendar view. Cheddar does not create, edit, or delete Google Calendar events. Google handles account sign-in; Cheddar does not receive your Google password.

3. Local storage and security

OAuth client settings and access and refresh tokens are stored in protected local configuration and token files. In the configured Raspberry Pi deployment, the token is kept outside the web root in a private directory accessible to the dashboard's operating-system account. The directory uses owner-only permissions, and the token file uses owner-only read and write permissions.

The stored refresh token allows Cheddar to renew access without asking you to sign in each time. Updated tokens are saved using an atomic replacement. Tokens are not embedded in the dashboard's browser JavaScript or in this public website.

These protections rely on operating-system access controls; they are not a claim that the files are encrypted at rest. The device owner and authorized administrators control the device and its backups. Copies retained during authorization, setup, or migration must be managed separately.

4. Caching and retention

Cheddar caches event information locally in the dashboard server's memory to keep the Calendar view responsive. The current integration checks whether cached results need refreshing after approximately 15 minutes. Older results may remain available when synchronization fails.

The refresh interval is not an automatic deletion deadline. Cached entries remain until they are replaced, evicted from the bounded cache, or the dashboard process stops. The Calendar integration does not write its event cache to a persistent event database or event-cache file.

Event information is also sent to the local dashboard page and held in that page's memory for display. Browser-managed data and any manually created copies, screenshots, or device backups may require separate cleanup. OAuth token files remain on disk until the operator removes them.

5. How information is used and shared

Cheddar uses Calendar information for your local appointment display and synchronization. Calendar data is not sold, rented, or used for advertising. It is not published on this website or uploaded to the public website repository.

The Calendar integration communicates with Google's authorization and Calendar services to obtain authorization, refresh access, and retrieve events. These requests use Google's HTTPS endpoints. Retrieved event information is delivered to your local dashboard browser.

The public website does not provide a hosted calendar account or a remote Calendar data service. Other features, such as weather and media, use their own services and do not receive Calendar event data from this integration.

6. Revoke access and delete local data

Revoke Google Calendar access

  1. Open your Google Account's third-party connections.
  2. Select the entry for Cheddar, or the OAuth application name used when you connected your dashboard, and review its access to your Google Account.
  3. Choose the option to remove access and confirm.

Google then prevents the revoked authorization from obtaining more Calendar information. Revoking access does not automatically erase event data already cached on the dashboard or remove local credential files. Google's account-access instructions explain the available controls.

Delete locally stored Calendar information

The Raspberry Pi's owner or an authorized administrator can perform these steps:

  1. Revoke Cheddar's Google access and stop the dashboard process so that its in-memory event cache is cleared and it cannot immediately fetch the data again.
  2. Delete the configured Calendar token file and any retained token copies from authorization, setup, migration, or backups. If removing the integration entirely, also remove its saved Calendar client settings and copies of those settings, while preserving configuration needed for other dashboard features.
  3. Close or reload the Calendar page and clear any browser-managed dashboard data. Remove any separate exports, screenshots, or backup copies you created.
  4. If continuing to use other dashboard features, start Cheddar again without a saved Calendar token.

Restarting the dashboard alone clears the server's in-memory cache but does not delete OAuth credentials. If access is still authorized, Cheddar may fetch events again. These local deletion steps do not delete events from your Google Calendar. This website cannot perform deletion on your device.

7. This public website

This website contains static information pages. It has no logins, forms, analytics, tracking scripts, or third-party embedded content. It does not request access to Google Calendar, store OAuth credentials, or receive appointments from your dashboard.

When this site is hosted on GitHub Pages, GitHub may process standard request information, such as visitor IP addresses and browser details, under its privacy statement. Links to other websites open services governed by their own policies.

8. Questions and policy changes

For help removing data on a particular device, contact that device's owner or administrator. The project's public maintainer profile is corbelltony on GitHub.

This policy may be updated when Cheddar's Calendar integration or this website changes. The date at the top identifies the latest revision.
